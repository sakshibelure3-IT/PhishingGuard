# PhishingGuard - Browser Based Phishing Detection System

A browser-based phishing detection system designed to identify suspicious websites in real time and alert users.

## Project Overview
The project analyzes website URLs and webpage-related features to classify sites as safe or suspicious. It includes a browser extension, a web dashboard, authentication, scan history, and profile management.

## Technologies
- HTML, CSS, JavaScript
- Chrome Extension API
- Python (Flask)
- Node.js / Express (described in the project report)
- MongoDB
- JWT authentication
- Chart.js

## Main Features
- Real-time URL analysis
- HTTPS validation
- Suspicious TLD detection
- URL length and suspicious-character checks
- Suspicious keyword detection
- Warning messages for detected threats
- Login and registration
- Scan history and dashboard statistics
- User profile

## Repository Note
The original academic project report is included in `docs/project-report.pdf`. The report documents the implementation, source code, screenshots, future scope and conclusion.

## Local Backend
The report uses a Flask backend on port 5000 and MongoDB for data storage. Configure your MongoDB connection and secret key through environment variables before running.
