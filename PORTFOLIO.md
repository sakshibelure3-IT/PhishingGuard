# Portfolio Summary

## Browser Based Phishing Detection System (Extension)

**Role:** Student Project  
**Institution:** Rajarshi Shahu Mahavidyalaya, Latur  
**Academic Year:** 2025-2026

### What it does
A Chrome browser extension that checks URLs in real time and alerts users when suspicious patterns are detected.

### Key implementation
- Frontend: HTML, CSS, JavaScript
- Browser integration: Chrome Extension API
- Backend: Python Flask
- Database: MongoDB
- Authentication: JWT
- Detection: rule-based URL analysis

### Detection examples documented in the project
- Missing HTTPS
- Suspicious TLDs
- Excessively long URLs
- Suspicious characters / lookalike patterns
- Suspicious keywords combined with hyphens
- Excessive hyphens in domain names

### User features
- Registration and login
- Security dashboard
- Scan history
- User profile
- Threat severity indicators
